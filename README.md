# PART 5: Shopping Cart Hands-On 🛒
Program dimana fitur keranjang belanja diimplementasikan secara langsung ke dalam aplikasi Flutter. Pada tahap ini, pengguna dapat menambahkan produk ke keranjang, melihat daftar barang yang dipilih, mengubah jumlah pembelian, menghapus item, serta melihat total harga yang diperbarui secara otomatis. Fitur ini dikelola menggunakan state management seperti Provider agar data pada keranjang dapat berubah secara real-time sesuai dengan interaksi pengguna.
